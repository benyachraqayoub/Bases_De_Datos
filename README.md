# 📚 Mis Estudios de Bases de Datos (SQL & NoSQL)

¡Bienvenido/a a mi repositorio de aprendizaje sobre bases de datos! Este espacio está dedicado a compilar todo mi progreso, apuntes teóricos y ejercicios prácticos sobre el diseño, administración y consulta de sistemas de gestión de bases de datos (DBMS).

El objetivo de este repositorio es servir como bitácora de estudio y portafolio personal, demostrando el dominio desde los conceptos teóricos fundamentales hasta la implementación práctica en tecnologías Relacionales (SQL) y No Relacionales (NoSQL).

---

## 🗺️ Mapa de Ruta del Aprendizaje

- [x] Fundamentos y Almacenamiento de la Información
- [ ] Modelado de Datos y SQL Completo
- [ ] Arquitecturas NoSQL (Orientado a Documentos, Clave-Valor, Grafos)
- [ ] Optimización de Consultas y Ajuste de Rendimiento (Tuning)

## 📝 Resumen de Contenidos

### 🏛️ Teoría General y Fundamentos
* **Capítulo 1: Almacenamiento de la Información**
  * Conceptos clave sobre cómo los sistemas operativos y los DBMS gestionan los archivos de datos.
  * Introducción a las estructuras de almacenamiento físico y lógico.

### 🧪 Evaluaciones y Ejercicios
* **Test - Capítulo 1:** Autoevaluación diseñada para consolidar los conocimientos teóricos del primer módulo. Contiene tanto la hoja de preguntas como la de respuestas corregidas para el repaso activo.

### 💾 Tecnologías Relacionales (SQL)
*(Próximamente)* Aquí se incluirán scripts `.sql`, diagramas entidad-relación (DER) y proyectos prácticos utilizando lenguajes de consulta estructurados.

### 📊 Tecnologías No Relacionales (NoSQL)
*(Próximamente)* Espacio reservado para el modelado de datos flexible, bases de datos documentales, en caché y almacenes de clave-valor.
