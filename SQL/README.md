# 💾 Prácticas de SQL (Bases de Datos Relacionales)

Módulo dedicado al diseño, implementación, normalización y consulta de bases de datos utilizando el lenguaje estructurado SQL.

## 📚 Guías Teóricas y Comandos (Gamma.app)
He preparado estas dos guías visuales de 10 páginas para dominar los fundamentos y la sintaxis de SQL:

* **[📄 Descargar/Ver: Aprendiendo Bases de Datos desde Cero (PDF)](./Aprendiendo-Bases-de-Datos-desde-Cero.pdf)**
  * *Contenido:* Anatomía de una tabla (filas, columnas, tipos de datos), las 3 anomalías de datos (inserción, borrado, actualización), y cómo solucionar el caos separando tablas mediante Llaves Primarias (PK) y Foráneas (FK).
* **[📄 Descargar/Ver: Dominando los Comandos SQL (PDF)](./Dominando-los-Comandos-SQL.pdf)**
  * *Contenido:* Guía de sintaxis DDL. Comandos esenciales para crear tablas (`CREATE`), modificarlas (`ALTER`), añadir reglas (`CHECK`), vaciarlas (`TRUNCATE`) y eliminarlas (`DROP`).

## 🛠️ Tecnologías Planificadas
* **Motores:** PostgreSQL / MySQL / SQLite
* **Contenidos Prácticos:** Lenguaje DDL, DML, Consultas Avanzadas (JOINS), Índices y Vistas.
