# 💾 Prácticas de SQL (Bases de Datos Relacionales)

Módulo dedicado al diseño, implementación, normalización y consulta de bases de datos utilizando el lenguaje estructurado SQL.

## 📚 Material Teórico y de Referencia

### 🎓 Recursos del Profesor
* **[📄 Descargar/Ver: Capítulo 2 - Bases de Datos Relacionales (PDF)](./cap2-bases-de-datos-relacionales.pdf)**
  * *Contenido:* Material oficial del curso sobre los fundamentos, conceptos clave y arquitectura de los modelos relacionales.

### 🚀 Guías Visuales Propias (Gamma.app)
He preparado estas guías visuales de 10 páginas para dominar los fundamentos, la sintaxis y los comandos de SQL:

* **[📄 Descargar/Ver: Aprendiendo Bases de Datos desde Cero (PDF)](./Aprendiendo-Bases-de-Datos-desde-Cero.pdf)**
  * *Contenido:* Anatomía de una tabla (filas, columnas, tipos de datos), las 3 anomalías de datos (inserción, borrado, actualización), y cómo solucionar el caos separando tablas mediante Llaves Primarias (PK) y Foráneas (FK).
* **[📄 Descargar/Ver: Dominando los Comandos SQL (PDF)](./Dominando-los-Comandos-SQL.pdf)**
  * *Contenido:* Guía de sintaxis DDL. Comandos esenciales para crear tablas (`CREATE`), modificarlas (`ALTER`), añadir reglas (`CHECK`), vaciarlas (`TRUNCATE`) y eliminarlas (`DROP`).
* **[📄 Descargar/Ver: Guía Definitiva de Comandos SQL para PostgreSQL (PDF)](./Guia-Definitiva-de-Comandos-SQL-para-PostgreSQL.pdf)**
  * *Contenido:* Manual enfocado en PostgreSQL. Explicación práctica paso a paso de comandos de definición (**DDL**), manipulación (**DML** con `INSERT`/`UPDATE`/`DELETE`) y consultas avanzadas (**DQL** con `SELECT`, `WHERE`, `ORDER BY` y `LIMIT`).
